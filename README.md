# Interlanguage Studies — Web

Página web de Interlanguage Studies. Archivo único autocontenido (HTML + CSS + JS + imágenes en base64).

## Archivo principal

- [interlanguage_web_pastel_7.html](interlanguage_web_pastel_7.html) — página completa

## Cómo verla en local

Basta con abrir el archivo directamente en el navegador:

```bash
open interlanguage_web_pastel_7.html
```

O, si prefieres servirla desde un servidor local (recomendado si vas a depurar con herramientas del navegador):

```bash
python3 -m http.server 8000
# luego abre http://localhost:8000/interlanguage_web_pastel_7.html
```

## Desarrollo con Claude Code

Abre esta carpeta con `claude` desde la terminal para seguir editando el proyecto. El archivo no tiene dependencias externas de build (no hay `npm install` que ejecutar); es HTML plano.
