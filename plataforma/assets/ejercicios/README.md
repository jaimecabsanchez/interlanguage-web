# Ilustraciones de ejercicios

Banco editorial común para las actividades con apoyo visual.

- WebP cuadrado optimizado a 720 px para carga rápida.
- Ilustración pintada, textura suave y viñeta orgánica.
- Un único concepto reconocible, sin texto, UI ni marca de agua.
- Nombre semántico en inglés, minúsculas y con guiones.
- Toda incorporación debe registrarse en `motor/visual-assets.js`.
- El contenido declara `visual: "clave"`; nunca dibuja el emoji.

El tratamiento cambia por CSS según `p12`, `p34`, `p56` o `eso`, pero el recurso y su significado proceden siempre del mismo manifiesto.
